    三 · 交互与视觉规格

    项规格
    命中证据带位于 prototype-note-main 下方、行内展开；整条 <a> 可点击进入原笔记；Chunk 文本桌面最多两行（-webkit-line-clamp: 2）。仅语义搜索开启且返回 bestChunk 时出现。
    命中类型semantic 命中只显示"语义相关"徽标，不制造伪高亮；关键词命中用 <mark> 高亮实际查询词。
    "另外命中 N 处"弱链接样式；点击后在当前证据带内向下展开最多 3 条额外片段，不弹 modal。
    普通笔记无 Chunk 证据时完全保持现有密度，不显示空证据框。
    状态与反馈正在检索保留列表高度 skeleton；Vector 失败降级时列表顶部浅琥珀弱提示；0 结果提示"没有找到笔记"并建议缩短问题/切换模式/清除筛选。
    知识库布局左栏 280px（<900px 时改为单列堆叠）prototype-panel 仅负责切换；右侧详情 prototype-panel-head.padded + 新增"知识图谱 / 笔记"两个页签。"保存图谱 / 生成提案"放在图谱页签工具栏右侧，不与"从笔记选择"混用。
    节点圆角矩形，左边 3px 色条区分概念/实体/主题/论断，同时显示中文类型不靠颜色；label 最多两行，完整文本进 tooltip；选中用强调色边框 + 轻量 ring。
    节点类型色概念 实体 主题 论断
    关系边默认 1.5px 中性细线；线段中点中文关系标签（包含/使用/依赖/相关）；选中节点仅高亮一跳关系；缩放 <0.6 隐藏关系文字；未识别英文 relation 原样显示。
    节点详情未选中不占宽度；点击节点从画布右侧展开 288px 面板，展示 label、类型、置信度、来源笔记；来源笔记映射到知识库链接，点击打开。<900px 时改为画布上方覆盖式窄面板；移动端改为画布下方。
    warnings非空时画布上方一行浅琥珀提示，默认只显示第一条和数量；点击"查看"展开全部；不使用错误红色（图谱仍可保存）。已保存图谱重新加载仍展示对应 warnings。
    画布规格桌面最小高度 520px / 1024px 下 460px / 移动端 420px；极淡点阵背景；内置缩放/平移/拖拽/Fit View；提供"重新布局"；>20 节点可折叠 MiniMap（此处 12 节点不显示）；>60 节点关闭边动画。
    可访问性控制按钮中文 aria-label；focus ring 不移除；对比度 ≥4.5:1，颜色不是类型唯一表达；动效 150–220ms 且遵守 prefers-reduced-motion。
    说明：上方画布为纯 HTML/SVG 交互模拟，用于设计确认——支持拖拽节点、滚轮缩放、按钮缩放/适应/重排、点击节点弹出右侧详情、明暗切换、warnings 展开、"另外命中 N 处"展开。实现阶段用 React Flow（@xyflow/react）+ dagre 承载同款样式。第一阶段不展示"关系原文证据"（evidenceChunkIds 属第二阶段），界面不伪造尚不存在的数据。
