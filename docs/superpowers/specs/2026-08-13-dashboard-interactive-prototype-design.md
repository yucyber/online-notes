# Dashboard 全站双主题交互原型设计

日期：2026-08-13  
交付物：`docs/superpowers/mockups/notes-list-yuque-preview.html`

## 目标

把现有“我的笔记”单页原型扩展为可通过左侧导航切换的完整 Dashboard 交互原型，并建立统一的浅色、暗色视觉体系。原型覆盖主要管理页面、版本页和编辑器工作区，同时重新设计 AI 助手入口与对话面板。

本轮只调整静态原型，不修改真实 React 页面、API、权限和业务行为。原型确认后，真实页面改造另行制定实施计划。

## 设计基线

- 延续已确认的 Calm Minimal 黑灰简约方向。
- 浅色以冷灰白、白色和深石墨为主；暗色以中性炭黑、分层深灰和柔和浅灰文字为主。
- 雾蓝只用于 focus、链接、选中和必要的状态提示，不作为大面积背景。
- 不使用蓝紫渐变、玻璃拟态、厚重阴影、卡片抬升、发光描边或 emoji 图标。
- 中文采用系统中文无衬线字体栈，图标使用统一的 Lucide 风格线性 SVG。
- 浅色与暗色使用同一套语义 token，各页面不得建立独立主题色。

## 原型架构

采用“单壳层、多视图”结构：

- 全局壳层包含左侧导航、顶部栏、页面内容区和 AI 助手。
- 各页面是同一 HTML 中的独立 `<section data-view="...">`。
- 左侧导航切换当前视图，不刷新页面。
- 当前页面写入 URL hash，例如 `#dashboard`、`#notes`、`#editor`；刷新后恢复当前页面。
- 顶部主题按钮切换浅色／暗色，所有视图和 AI 助手同步变化。
- 主题选择写入 `localStorage`，首次打开优先使用已保存选择。
- 导航项的选中状态、面包屑、页面标题和 AI 上下文随视图同步变化。

## 全局壳层

### 左侧导航

- 保留品牌、工作台分组、管理分组和底部设置。
- 工作台：仪表盘、我的笔记、知识库、活动日志。
- 管理：分类管理、标签管理。
- 消息中心通过顶部通知入口进入，版本页和编辑器通过笔记相关入口进入。
- 选中态使用浅石墨或深灰背景，不使用蓝色大描边和左侧装饰线。
- 桌面端可收起；1024px 以下为覆盖抽屉。

### 顶部栏

- 保留导航开关、面包屑、主题、通知和用户入口。
- 删除常驻“在线”技术状态。
- 面包屑使用稳定中文名称；动态 ID 显示笔记标题，不显示原始 UUID 或英文 `versions`。
- 通知未读通过低干扰小点表达，不绘制强蓝色外框。

### 页面骨架

- 页面标题区包含标题、简短说明和最多一个主操作。
- 内容优先使用开放式区域、细分隔线和轻量面板，不把所有内容包成大圆角卡片。
- 页面最大宽度、标题基线、控制带、空状态和分页保持一致。
- 桌面端保持中等密度；移动端主操作、筛选和分页允许换行但页面不得横向滚动。

## 双主题设计系统

### 浅色

- 页面背景：冷灰白。
- 侧栏：比页面略深的灰白。
- 内容面：白色。
- 次级面：浅石墨灰。
- 主文字：深石墨。
- 辅助文字：中性灰。
- 主操作：黑色背景、白色文字。

### 暗色

- 页面背景：接近 `#181817` 的中性炭黑，不使用偏蓝黑。
- 侧栏：略浅于页面的深灰，保留可识别的布局边界。
- 内容面：比背景提高一层明度，表单和次级面再提高一层。
- 主文字使用柔和灰白，避免纯白造成高眩光。
- 边框只比相邻表面略亮，依靠层级而不是强描边区分区域。
- 主操作使用浅色背景与深色文字；危险操作保持克制红色。
- 浮层和 AI 面板允许使用克制阴影，其余面板不使用大阴影。

### 共享交互

- focus-visible 使用 2px 雾蓝轮廓。
- hover 仅改变表面一档或文字颜色。
- 状态过渡为 150–200ms；`prefers-reduced-motion` 下关闭非必要动效。
- 正文和重要控件满足 WCAG AA；点击目标在移动端至少 44×44px。

## 页面设计

### 仪表盘

- 取消三张巨大统计卡，顶部使用一行紧凑数字概览。
- 主体由“最近笔记”和“继续写作”组成，突出可继续的工作。
- 分类与标签状态降级为轻量辅助栏，不展示没有决策价值的大号零值。
- 空数据时提供具体下一步，不展示大面积空白卡片。

### 我的笔记

- 延续已完成的开放式轻列表、紧凑筛选、hover 预览和弱化推荐栏。
- 浅色和暗色保持相同信息层级。
- 从笔记行可进入编辑器和版本页原型。

### 知识库

- 使用“集合目录 + 笔记内容”的两栏工作区。
- 左侧展示知识库列表、数量和创建入口；右侧展示选中知识库的笔记与图谱概览。
- 创建表单使用可展开内联区或抽屉，不长期占据半屏。
- 无知识库时只保留一个聚焦空状态和创建按钮。

### 活动日志

- 将 `invitation_accepted` 等代码映射为中文动作文案。
- 按日期分组为时间线，突出操作者、动作、对象与时间。
- 类型筛选、日期范围、每页数量和分页集中到同一控制带。
- 行项目不使用独立圆角卡片墙。

### 分类管理

- 主体为可扫描的层级分类列表，展示名称、父级、笔记数和必要操作。
- 创建／编辑使用右侧面板，颜色作为辅助识别，不显示原始 hex 为主要内容。
- “健康度”缩成轻量提示区，仅在有可执行建议时出现。
- 空状态引导创建第一个分类。

### 标签管理

- 搜索、批量创建和同步计数合并为紧凑工具栏。
- 标签使用可扫描矩阵或表格，展示名称、颜色点、笔记数量与操作。
- 合并流程在选择标签后出现上下文工具栏，未选择时不占据大块空间。
- 删除、重命名和改色均使用一致的行内操作。

### 消息中心

- 待处理邀请和普通通知合并为统一收件箱。
- 顶部用“全部／邀请／未读”筛选区分内容。
- 每行展示类型图标、清晰中文标题、时间和上下文动作。
- 空状态保持紧凑，不绘制两个巨大空面板。

### 版本页

- 面包屑显示“工作台 / 我的笔记 / 测试 / 版本记录”。
- 主体使用版本时间线，展示当前版本、快照时间、创建者和内容变化摘要。
- 主操作为“创建快照”；每个历史版本提供“查看差异”和“恢复”。
- 无历史版本时说明自动保存与手动快照的区别，并提供创建入口。

### 编辑器工作区

- 编辑器不是本轮重新设计对象。现有 DOM 结构、三栏信息架构、组件位置、控件、尺寸、折叠逻辑和交互行为全部保持不动；原型只展示统一主题后的视觉结果。
- 左侧为品牌、返回我的笔记、搜索和笔记目录；中间为页头、工具栏和开放式正文；右侧为大纲。
- 编辑器路由继续跳过 Dashboard 全局侧栏和顶部栏，只使用编辑器自身工作区。
- 编辑器浅色继续使用当前冷灰白和白色纸张面，不调整已完成的 UI 布局。
- 编辑器暗色改为中性炭黑体系，不使用当前偏蓝的 `#0b1220 / #0f172a`。
- 暗色正文纸张只比页面背景略亮，正文使用柔和灰白；代码块、引用、表格和选中文本分别提高一个表面层级。
- 工具栏、浮层、属性面板、评论标记、AI 选区操作和大纲使用同一暗色语义 token。
- 雾蓝只用于当前目录、链接、focus 和文本选中；不把整条工具栏或侧栏染蓝。

## 墨点助手

### 收起状态

- 右下角使用 44px 黑灰圆形按钮，图标为抽象 `N ✦`／四角星，不再使用机器人图标。
- 默认只有细边框和轻阴影，不显示绿色在线点。
- hover 时只做轻微位移或星点旋转；生成中显示沿圆周移动的细环。
- 按钮不遮挡分页、删除按钮、编辑器滚动条和移动端安全区域。

### 展开状态

- 桌面端为右侧 360px 悬浮面板；移动端为底部抽屉。
- 顶部展示“墨点助手”、当前上下文和关闭按钮。
- 仪表盘／管理页上下文为“搜索全部笔记”；编辑器上下文为“已引用当前笔记”。
- AI 消息使用开放式文本布局，用户消息使用轻量灰色气泡，不堆叠厚重聊天气泡。
- 空状态提供三个快捷动作：总结当前笔记、提取待办、搜索知识库。
- 底部输入区包含上下文开关、输入框和发送按钮。
- 浅色使用白色纸张面板；暗色使用炭灰面板和柔和灰输入区，不使用发光或蓝紫渐变。

## 原型交互

- 左侧导航与顶部入口可切换九个视图。
- URL hash 与当前视图双向同步。
- 浅色／暗色切换立即作用于全站、编辑器与墨点助手。
- 侧栏支持桌面收起和移动抽屉。
- 墨点助手支持打开、关闭、快捷动作、上下文切换和模拟发送。
- 知识库选择、活动筛选、分类面板、标签选择、通知筛选、版本操作和笔记 hover 提供可感知演示状态。
- 编辑器提供返回笔记、目录切换、大纲收起和 AI 上下文状态的演示。

## 响应式

- 1440px：完整侧栏、顶部栏和页面多栏布局。
- 1024px 以下：全局侧栏为抽屉，多栏页面减少为主次两栏或单栏。
- 768px 以下：页面全部改为单栏，辅助区域移到主内容之后；墨点助手改为底部抽屉。
- 375px：标题操作、筛选、分页和编辑器工具栏无横向页面溢出；低频工具允许自身横向滚动。

## 验收标准

- 单个 HTML 可通过左侧导航与页面入口访问全部设计视图。
- 切换主题后所有页面、浮层、编辑器和墨点助手均使用一致的浅色或暗色层级。
- 截图中现有的大卡片墙、强蓝选中描边、常驻在线状态、英文事件代码、原始 UUID／`versions` 面包屑和巨大空面板均被替换。
- 墨点助手收起时低干扰，展开后具备明确上下文和可用快捷动作。
- 1440、1024、768、375px 下无页面横向溢出、遮挡和不可点击控件。
- 键盘焦点清晰，控制台无错误，原型不请求真实 API。

## 非目标

- 不在本轮修改 `notes-frontend/src` 中的真实实现。
- 不改变页面业务信息架构、数据模型、ACL、搜索算法、推荐算法和协作流程。
- 不实现真实 AI 对话、版本恢复、知识图谱或后台请求；交互只用于设计演示。
