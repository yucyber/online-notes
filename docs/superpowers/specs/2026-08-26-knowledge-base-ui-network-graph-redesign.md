# 知识库 UI 与关系网络图谱重设计

## 目标

知识库页面以 `docs/ui-mockups/phase-one-search-and-knowledge-graph-ui-20260826.html` 和用户确认的图二为唯一视觉基准。删除当前连体式工作区和 Dagre 分层布局，不保留旧视觉兼容。

## 页面结构

- 页面正文沿用项目全局内容宽度，不另设放大的容器。
- 标题区与设计稿一致：左侧 eyebrow、标题和描述，右侧“新建知识库”。
- 主工作区使用两列网格：左栏固定 `280px`，列间距 `24px`，右栏占剩余宽度。
- 左栏和右栏分别使用独立的 `prototype-panel`，圆角、边框和背景均使用项目 `--product-*` token。
- 右栏依次包含：知识库标题栏、页签、图谱工具栏、warning、图谱画布。
- 页签高度、toolbar padding、按钮尺寸、warning margin 均照 HTML 稿，不沿用当前 `knowledge-base-workspace` 连体布局。

## 图谱呈现

- 图谱是无根关系网络，不表达父子层级，不使用 Dagre、树形或思维导图布局。
- 初始布局采用确定性的力导向计算：关系边作为弹簧、节点之间互斥、整体向画布中心收敛，并通过固定初始位置保证同一数据得到稳定结果。
- 高连接节点自然靠近网络中心；关联节点围绕其分布；孤立节点放在外围。
- React Flow 只负责渲染和交互，布局算法保持为独立纯函数，便于测试。
- 边使用直线或轻微曲线，不使用正交折线；中文关系标签位于边中点；缩放低于 `0.6` 时隐藏标签。
- 节点尺寸接近设计稿：宽度约 `128–176px`，内容最多两行；类型通过左侧 3px 色条区分。

## 画布与交互

- 桌面画布最小高度 `480px`，内容适应画布，不因节点数量撑高页面。
- 保留滚轮缩放、拖动画布、拖动节点、放大、缩小、适应画布和重新布局。
- “重新布局”重新运行同一确定性关系网络算法，不切换成圆形或树形。
- 点击节点突出自身和一跳邻居，其余节点与边降低透明度。
- 节点详情默认隐藏；选中后在画布右侧打开 `288px` 详情栏，展示类型、置信度和来源笔记。
- `<=900px` 时详情栏覆盖在画布右侧；`<=767px` 时详情栏移到画布下方，图例隐藏。

## 状态与数据

- 已保存图谱、待保存提案、生成中、保存中、空图谱和 warning 行为保持现有 API 语义。
- 保存图谱按钮仅在存在未保存提案时出现。
- warning 数组为空时不显示 warning 区域；存在时默认展示第一条，可展开全部。
- 不修改知识图谱 API 数据结构。

## 验收标准

- 1440px 页面在结构、留白、边框、按钮、页签和画布比例上与确认的图二一致。
- 图谱不存在明显的单向层级、主干或整齐列阵，视觉上是关系网络。
- 12 个左右节点能在首屏画布内完整显示且标签可读。
- 桌面和 `390px` 移动端无横向页面溢出、面板遮挡或节点裁切。
- 原有生成、保存、warning、页签和来源笔记操作测试继续通过。
- 新增布局测试，验证结果确定、节点不重叠、存在二维分散且边端点有效。

## 不在本次范围

- 不修改图谱生成模型、节点和关系抽取逻辑。
- 不增加新的后端接口或图谱字段。
- 不实现社区发现、时间演化或 3D 图谱。
