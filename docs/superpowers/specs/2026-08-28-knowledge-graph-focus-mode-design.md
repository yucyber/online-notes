# 知识图谱全屏专注模式设计

## 背景与目标

当前知识图谱位于知识库页面右栏，节点增多后可用画布不足。专注模式应提供接近全屏的关系网络画布，同时允许用户在模式内切换知识库，不必退出专注模式、回到列表、重新选择并再次进入。

本设计只调整前端呈现与交互，复用现有知识库、笔记关联、saved graph 和 proposal graph API，不修改图谱生成、保存或数据结构。

## 方案选择

采用“全屏画布 + 可唤出的左侧知识库抽屉”。相比永久侧栏，它不会持续占用画布；相比独立路由，它不引入新的导航和状态同步边界，能以较小改动复用当前页面状态。

普通知识库页面保留现有双栏结构。只有用户点击“专注模式”后，才在当前页面上方显示 fixed 全屏层。

## 专注模式结构

- 全屏层覆盖 dashboard 内容区域和导航，使用现有浅色、暗色 design token。
- 顶部工具区显示当前知识库名称、图谱状态徽标、“知识库”抽屉按钮和“退出专注模式”按钮。
- 图谱画布占据顶部工具区之外的全部可用空间，保留筛选、图例、缩放、平移、适应画布、重新布局和节点来源详情。
- saved graph 显示“已保存图谱”，存在 proposal graph 时显示“待保存提案”，语义与现有 `graphProposal || savedGraph` 一致。
- 生成提案和保存图谱继续使用现有操作与禁用条件，不在专注模式中创造第二套业务逻辑。

## 知识库抽屉与切换

- 桌面端抽屉从左侧覆盖画布，宽度约 `300px`；打开或关闭时不改变画布容器尺寸，避免 React Flow 重新排布和视觉跳动。
- 抽屉包含知识库搜索框、知识库列表、当前项标识和描述摘要；仅当前知识库显示现有 `links.length` 笔记数，不为其他知识库补查计数或新增后端请求。
- 点击知识库后立即更新当前 `selectedId` 并关闭抽屉，专注模式保持打开。
- 切换期间保留旧画布并增加不可交互的轻量 loading 覆层；新知识库数据成功返回后原位替换。
- 加载失败时不显示来自前一个知识库的图谱作为新结果。界面显示明确错误和“重试”操作，抽屉仍可打开并切换其他知识库。
- 没有笔记、没有 saved graph 或没有知识库时，沿用现有空态含义，并保持退出入口可用。

## 会话状态

专注模式生命周期内，以 knowledge base ID 为键保存每个知识库的画布视口、节点位置、文本筛选和节点类型筛选。切换回来时恢复该知识库上次状态；首次打开某知识库时使用现有确定性布局并适应画布。

退出专注模式后不持久化这些状态到后端或浏览器存储。再次进入时从当前页面选择的知识库开始，使用默认视口和筛选，避免引入跨会话状态迁移。

## 键盘、焦点与响应式

- 打开专注模式后，焦点进入全屏层；退出后回到触发按钮。
- 抽屉打开时限制键盘焦点在抽屉内，并将焦点放到搜索框。
- `Escape` 在抽屉打开时先关闭抽屉；抽屉关闭时再次按下才退出专注模式。
- 所有图标按钮提供可读的 `aria-label`，状态徽标不只依赖颜色表达。
- 窄屏下抽屉改为接近全宽的 sheet；画布仍占满剩余视口，工具区允许必要换行但不能造成页面横向滚动。
- 背景页面在专注模式期间禁止滚动，退出时恢复原页面滚动位置。

## 组件与状态边界

- `KnowledgeBasesPage` 持有是否进入专注模式的页面级状态，并继续复用 `useKnowledgeBasePage` 的当前知识库和加载行为。
- 新增独立的专注模式容器组件，负责全屏层、抽屉、键盘和焦点管理；它通过 props 使用现有知识库列表、选择动作和图谱操作。
- `KnowledgeGraphPanel` 与 `KnowledgeGraphCanvas` 继续作为普通模式和专注模式共享的图谱入口，只增加专注模式所需的布局参数或会话状态回调，不复制图谱工具栏与请求逻辑。
- 切换请求沿用 `useKnowledgeBasePage`；需要防止较早请求晚返回后覆盖当前知识库，新结果只在请求对应当前 `selectedId` 时生效。

## TDD 与验收

实现必须先增加失败测试，再做最小修改：

- 进入和退出专注模式，退出后焦点回到触发按钮。
- 在专注模式内打开抽屉并切换知识库，模式不退出，图谱与状态徽标随选择更新。
- `Escape` 的两阶段行为和抽屉焦点约束。
- 快速切换时陈旧请求不能覆盖当前图谱。
- loading、接口失败、无知识库、无笔记、无图谱及恢复操作。
- saved graph 与 proposal graph 的状态区别。
- 每个知识库的视口、节点位置与筛选在本次专注会话内恢复。
- 桌面、窄屏、浅色和暗色模式无横向溢出，背景页面不滚动。
- 浏览器验收覆盖缩放、平移、重排、节点来源、知识库切换、控制台错误和 React hydration warning。

最终运行前端定向测试、全量 Jest、`npm run type-check`、正式 build 和 `git diff --check`。主观视觉效果仍由用户确认。

## 不在本次范围

- 不修改普通页面左侧知识库列表为永久可折叠侧栏。
- 不新增独立图谱路由或可分享的专注模式 URL。
- 不修改后端、GraphRAG、图谱生成模型、proposal 生成规则或保存格式。
- 不持久化用户的画布位置、筛选条件或抽屉状态。
