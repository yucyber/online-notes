# 编辑器高还原精修设计

**日期：** 2026-08-12  
**状态：** 已确认结构方向  
**视觉基准：** `docs/ui-mockups/editor-calm-minimal-20260810.html`

## 1. 目标

在不修改笔记保存、协同、权限和路由行为的前提下，让真实编辑器页的布局、视觉层级和交互反馈明显接近 Calm Minimal 设计稿，并以这套精修标准继续约束其他页面。

本轮优先解决当前真实页面与设计稿之间最明显的差异：全站侧栏与编辑器侧栏重复、属性区过度占高、工具栏拥挤、编辑纸张层级不清晰，以及折叠和选中反馈不统一。

## 2. 已确认结构

采用“编辑器专用工作区”，不在编辑器页面叠加常规 Dashboard 壳层：

- `/dashboard/notes/[id]` 和 `/dashboard/notes/new` 使用编辑器专用布局。
- 设计稿左侧栏替代全站侧栏，包含品牌、搜索/筛选入口、笔记导航和返回工作台入口。
- 编辑器顶部仅保留返回、标题、保存状态、主题、协作与面板控制，不显示常规 Dashboard 面包屑、账户卡片或网络诊断条。
- 中间区域由紧凑工具栏和纸张正文组成，正文是视觉主角。
- 分类、标签、可见性和目录等低频信息进入可折叠右侧属性面板；桌面默认收起，窄屏使用 Drawer。
- 仪表盘、分类、标签、设置等非编辑器页面继续使用现有全站 `AppShell`。

编辑器页仍保留返回全站工作区的明确入口，因此专用布局不会形成导航死路。

## 3. 视觉与排版

- 页面背景、面板、边线、文字和强调色继续使用现有 product/editor tokens，不另建一套颜色系统。
- 桌面左侧栏基准宽度 236px，收起后保留 52px 控制轨；右侧属性面板基准宽度 280px。
- 编辑纸张最大宽度控制在适合长文阅读的范围，居中显示并保留充足留白。
- 属性摘要不再横跨正文上方；标题与保存状态保持轻量，不形成第二个大卡片。
- 工具栏允许控件分组和“更多”菜单，但 1440px 编辑器默认状态不得出现横向滚动条。
- 圆角、边框和阴影保持克制；不增加渐变、玻璃拟态、悬浮放大或装饰性动画。

## 4. 交互规则

- 左右面板分别折叠，桌面记忆用户显式选择；移动端不沿用桌面展开状态。
- hover、active、focus-visible 使用统一 token，过渡时长 150–200ms。
- 所有图标按钮保留可访问名称、Tooltip、键盘操作和至少 44×44px 点击区域。
- `prefers-reduced-motion` 下关闭非必要过渡。
- 保存状态仅显示“持续保存 / 保存中 / 已保存 / 保存失败”；失败重试沿用现有安全保存链路。
- 不恢复 `ws[...]`、`sync[...]`、原始延迟、常驻“保存/重连/触发同步”等诊断 UI。

## 5. 响应式规则

- 1440px：左侧栏、正文、可选右侧面板组成完整工作区，工具栏无横向滚动。
- 1024px：左侧栏可收起，右侧属性默认收起，正文保持可读宽度。
- 768px 及以下：左右面板改为 Drawer，顶部动作收敛到必要操作和更多菜单。
- 375px：页面本身不得横向溢出；工具栏可在自身容器内滚动，但不得推动正文宽度。

## 6. 组件边界

- `app/dashboard/layout.tsx`：识别编辑器路由并选择普通工作区或编辑器工作区，业务页面不自行复制壳层。
- `NoteEditorShell`：只编排编辑器数据和区域，不承载全站导航样式。
- `NoteEditorHeader`：标题、保存状态和工作区级动作。
- 编辑器左侧导航：品牌、搜索、笔记入口和返回工作台。
- `NoteEditorMetadataPanel`：右侧低频属性与目录，保持可折叠/Drawer 双形态。
- `TiptapToolbar`：按使用频率分组，低频命令进入更多菜单，命令接口不变。

不拆分保存、Yjs、ACL 或 Tiptap 命令逻辑；本轮只调整呈现和布局编排。

## 7. 实施批次

1. 编辑器专用路由壳层与设计稿左侧栏。
2. 标题、属性面板、正文纸张和工具栏密度精修。
3. 折叠、Drawer、hover/focus/reduced-motion 交互精修。
4. 将形成的间距和交互规则同步到其他页面，最后集中全量验收。

每批只运行受影响 Jest、`type-check` 和必要浏览器断点检查；全部完成后统一执行全量 Jest、Lint、production build 和真实浏览器验收。

## 8. 验收标准

- 编辑器真实路由不再同时出现全站侧栏与内部侧栏。
- 设计稿中的单侧栏、紧凑页头、工具栏、纸张正文和可折叠属性区在真实数据页面成立。
- 1440、1024、768、375px 页面无横向溢出，1440px 工具栏无横向滚动。
- 浅色和深色主题的正文、标题、属性文字满足可读性要求。
- 面板折叠、主题、协作、属性、工具栏和返回导航可通过鼠标与键盘操作。
- 保存、协同、权限、分类与标签数据行为不因布局精修而改变。
- 浏览器控制台无新增 error/warn；最终全量质量门禁退出码为 0。

## 9. 非目标

- 不重做编辑器业务功能、保存协议、协同协议或权限模型。
- 不新增第三方 UI、动画或状态管理依赖。
- 不逐像素复制静态 HTML 的演示外框、介绍文案或无法复用的装饰。
- 不在本轮重新设计其他页面的信息架构。
