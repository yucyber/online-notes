# 编辑器布局自动保存与设置导航常驻设计

## 布局存储

编辑器继续使用自由拖拽宽度，不在设置页提供预设档位。`notes:editor-layout:v1` 只保存编辑器实际产生的布局值；新增独立 key `notes:editor-layout:auto-save:v1` 保存自动保存开关，缺省为开启。

关闭自动保存时，立即删除旧布局 key 并把共享 store 重置为当前视口默认布局。之后折叠、展开和拖拽仍可改变当前会话，但不再写入布局 key；所有布局消费者卸载后重新进入编辑器时，从默认布局开始。重新开启后，后续布局变更恢复持久化。

## 设置页

编辑偏好只保留“自动保存布局”开关，说明文字明确其保存对象是左栏宽度与折叠状态。移除窄、标准、宽三档控制。

左侧分组导航绑定 `.app-main` 滚动上下文，桌面端使用 `sticky top-20 self-start` 并限制自身高度；移动端继续使用横向导航。项目已有同类 sticky rail，但没有通用导航组件，也没有第二个需要共享激活态和响应式行为的设置页面，因此本期不抽公共组件。

## 验证

- store 测试覆盖默认开启、关闭清除、关闭后不写布局、重新开启恢复保存。
- 设置页测试覆盖开关调用、移除宽度预设以及桌面 sticky 导航契约。
