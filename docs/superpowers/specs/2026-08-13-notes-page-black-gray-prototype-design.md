# 我的笔记页黑灰简约原型设计

日期：2026-08-13  
范围：`docs/superpowers/mockups/notes-list-yuque-preview.html`

## 目标

将现有“我的笔记”静态原型调整为完整的 Dashboard 工作台视图，并在项目既有 Calm Minimal 基础上强化黑灰简约气质。原型用于确认视觉和响应式布局，不改变真实 React 页面、API、权限或业务行为。

## 设计依据

- 延续项目既有内容优先、浅色生产力工具方向。
- 使用冷灰白背景、白色内容面、深石墨主文字和灰阶辅助信息。
- 雾蓝仅用于链接、焦点和少量交互反馈，不作为大面积填充色。
- 不使用渐变、大面积品牌色、厚阴影、卡片抬升、emoji 图标或装饰性动画。
- 中文采用系统中文无衬线字体栈；图标使用内联 Lucide 风格 SVG。

## 页面框架

原型展示完整工作台，包括左侧全局导航、顶部栏、主笔记列表和右侧辅助信息区。

- 桌面端左侧栏宽约 224px，内容区占据剩余空间。
- 顶部栏包含侧栏开关、面包屑、主题、通知和账户入口。
- 主内容使用紧凑标题区、搜索筛选控制带、开放式笔记列表和底部分页。
- 右侧辅助栏与主列表通过留白和细竖线区分，不使用与主内容同权重的卡片。
- 页面最大内容宽度保持适合扫描，避免在超宽屏上过度拉伸。

## 左侧栏

- 背景使用比页面略深的冷灰色，并用一条细边线与内容区分隔。
- 品牌区保留黑色 `N` 字标和“在线笔记”，删除 `Workspace` 副标题。
- 导航沿用真实项目的信息架构：仪表盘、我的笔记、知识库、活动日志；管理分组包含分类管理和标签管理；设置固定在底部。
- 默认导航项无边框、无阴影；hover 使用极浅灰背景。
- “我的笔记”选中态使用浅石墨背景、深石墨文字和图标，不使用蓝色填充、左侧装饰线或独立图标框。
- 分组标题以弱文字和间距建立层级，避免连续分隔线。
- 桌面端允许收起；1024px 以下改为覆盖式抽屉，关闭后不占内容宽度。

## 顶部栏

- 高度约 56px，使用白色或接近白色背景与底部细线。
- 左侧显示侧栏控制和“工作台 / 我的笔记”面包屑。
- 右侧保留主题、通知和用户入口，移除常驻“在线”状态。
- 用户头像使用黑灰底色；图标按钮提供 hover、`focus-visible` 和可访问名称。

## 主内容区

### 标题与操作

- 标题使用约 26px 的深石墨字，说明文字降低对比度。
- “新建笔记”使用纯黑主按钮；“批量管理”使用轻量次级按钮。
- 主按钮不使用渐变、发光或大阴影。

### 搜索与筛选

- 搜索作为控制带主体，分类、状态与语义搜索为紧凑灰阶控件。
- 控件以浅灰表面和细边界区分，聚焦时才出现克制雾蓝轮廓。
- 搜索和筛选在中窄屏允许换行，不产生页面横向滚动。

### 笔记列表

- 列表取消明显的外层卡片感，以顶部细线和行间分隔线组织内容。
- 标题为主要扫描信息；更新时间、分类和标签数保持低对比度。
- hover 使用极浅石墨灰，标题可出现克制雾蓝；编辑和删除操作在 hover 或键盘聚焦时出现。
- 操作图标使用线性 SVG，不使用字符或 emoji。
- hover 预览采用白色纸张式浮层、细边框和克制阴影；摘要与标签均使用灰阶，键盘 `focus-within` 同样可触发。
- 分页放在列表底部，当前页使用黑色选中态。

## 右侧辅助区

- “猜你喜欢”和“继续写作”合并为一个低权重辅助栏。
- 通过左侧细竖线和留白与主内容区分，不绘制独立卡片背景或厚边框。
- 推荐项采用简短标题、轻量分类或时间信息；hover 只改变文字和浅背景。
- 右栏在桌面端 sticky；窄屏下移到列表之后，不挤压主内容。

## 响应式与可访问性

- 1440px：完整侧栏、主列表和右侧辅助栏。
- 1024px 以下：侧栏变为抽屉；主内容与辅助栏按可用宽度重新编排。
- 768px 以下：右侧辅助栏移到主列表下方；标题操作和筛选区允许换行。
- 375px：列表 meta 信息精简或换行，操作按钮保持至少 44×44px 点击区域，页面无横向溢出。
- 所有图标按钮具有可访问名称；交互控件有清晰 `focus-visible` 状态。
- 动效限制在 150–200ms，并在 `prefers-reduced-motion` 下关闭非必要过渡。
- 正文和重要控件对比度满足 WCAG AA。

## 原型交互

- 侧栏收起和移动抽屉开关可操作。
- 主题按钮可在浅色与深色令牌之间切换，但本轮视觉评审以浅色黑灰方案为主。
- 笔记行 hover／聚焦可展示预览和操作。
- 筛选控件、分页和主按钮提供明确的 hover、active 与 focus 状态。

## 验收标准

- 原型首次打开即可看见完整 Dashboard 框架，不再是孤立内容页。
- 黑灰层级占主导，蓝色只承担交互提示。
- 左侧栏、顶部栏、主列表和右侧辅助栏具有明确主次关系。
- 不出现 emoji 图标、渐变主按钮、厚重卡片墙或高饱和大色块。
- 在 1440、1024、768 和 375px 宽度下无横向溢出、遮挡或不可点击控件。
- 浏览器控制台无错误，关键交互可用，键盘焦点清晰。

## 非目标

- 不修改 `notes-frontend/src` 下的真实页面实现。
- 不新增业务功能、页面入口或数据字段。
- 不改变已有信息架构、权限规则、搜索语义或推荐算法。
