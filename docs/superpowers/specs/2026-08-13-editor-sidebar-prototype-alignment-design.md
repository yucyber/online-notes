# 编辑器目录、画布与滚动体验对齐设计

## 目标

调整编辑器左侧笔记目录、正文可用高度、右侧大纲和工具栏状态反馈，使其在浅色和暗色主题下与 `docs/superpowers/mockups/notes-list-yuque-preview.html#editor` 保持一致，并消除多层嵌套滚动感。

## 修改范围

- 返回入口：沿用现有返回行为，调整为原型中的轻量文字入口、间距和字号。
- 搜索框：保留现有搜索逻辑，仅对齐高度、圆角、边框、图标、字号和内边距。
- 目录标题：对齐原型的字号、字重、颜色和上下间距。
- 笔记列表：保留现有打开笔记行为；移除列表项文件图标，对齐行高、内边距、文字样式及选中态的细描边和背景。
- 空状态：保留现有逻辑，仅使间距和文字颜色与目录区域一致。

## 全高布局与滚动

- 左侧目录、正文区域和右侧大纲均填满工具栏以下的可视窗口。
- 正文画布的最小高度使用剩余可视高度，不再固定为 `520px`；短内容时画布延伸到底部，长内容时自然增长。
- 移除正文与右侧大纲之间的竖向分隔线。
- 编辑器主体只保留一个统一滚动容器，滚动条位于页面最右侧；正文和大纲不再各自显示滚动条。
- 右侧大纲在主体滚动时保持 sticky，并受可视窗口高度约束，但不建立独立滚动上下文。
- 左侧目录保持独立于正文的固定栏；仅当目录内容超过可视高度时在目录列表内部滚动。

## 工具栏状态同步

- 光标或选区变化时，工具栏同步当前文本的段落/标题级别和字号。
- 加粗、斜体、下划线、引用、行内代码、有序列表、无序列表和任务清单显示当前激活状态。
- 状态同步只更新控件值与 `aria-pressed`/激活样式，不改变现有编辑命令、工具栏位置或按钮顺序。
- 光标处于混合格式选区时，采用 Tiptap 对该选区返回的 active 状态，不额外弹出浮层。

## 明确不修改

- 左侧品牌区及 Logo。
- 左侧导航的展开、收起按钮与交互。
- 编辑器顶栏、工具栏的布局和按钮顺序、正文内容、属性面板及右侧大纲内容。
- 数据请求、搜索过滤方式、笔记切换及保存逻辑。
- 编辑器整体列宽和页面布局。

## 实现方式

在 `EditorWorkspaceSidebar.tsx` 中只移除目录项内的文件图标，保留现有语义元素和事件处理。在 `editor-tokens.css` 中修改目录、画布和编辑器主体滚动相关的局部 class，不引入影响其他页面的通用选择器。

工具栏通过 Tiptap editor 的 selection/transaction 更新获得格式快照，由 `NoteEditorShell` 传给 `TiptapToolbar`。工具栏 select 改为受控值，格式按钮使用同一份快照渲染激活态。

浅色和暗色均继续使用现有 product token，避免写死仅适配单一主题的颜色。

## 验证标准

- 返回入口、搜索框、目录标题和列表项的视觉层级与原型一致。
- 当前笔记选中项为细边框、主题背景和普通正文色，不再使用强调色文件图标。
- 搜索和点击笔记功能保持可用。
- 三栏填满工具栏以下的可视高度，短正文不再留下大块空白。
- 正文与大纲间无竖线，页面仅在最右侧显示一个主体滚动条。
- 点击不同格式的正文后，段落类型、字号和格式按钮状态正确变化。
- 顶栏、工具栏布局和按钮顺序、正文内容及其他编辑器功能不发生变化。
- 编辑器相关回归测试、TypeScript 检查和 lint 通过。
