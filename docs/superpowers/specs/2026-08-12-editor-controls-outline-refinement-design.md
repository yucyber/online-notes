# 编辑器控件与大纲收敛设计

## 目标

消除编辑器页头、工具栏和侧栏轨道中的重复入口，优化大纲、笔记属性、文本浮层与全屏滚动，同时保持 Calm Minimal 与语雀式轻量交互。

## 信息架构

- 左栏顶部依次放置品牌、返回“我的笔记”、搜索框和笔记目录。
- 页头使用紧凑面包屑“我的笔记 / 当前笔记”，右侧集中自动保存状态、评论、协作和笔记属性入口。
- 工具栏只负责正文格式与内容插入，不再放评论、协作等页面级操作。
- 笔记属性改为页头按钮触发的轻量 Popover，包含分类、标签和底部“查看历史版本”。
- 大纲从属性面板中独立，宽屏位于正文右侧，中窄屏使用抽屉。

## 交互设计

### 左侧栏

- 展开时，收起按钮只在侧栏右边界 hover 或键盘 focus 时显示。
- 收起后释放原有宽度，仅在页面左边缘保留轻量唤出触点。
- 返回入口位于侧栏上部，目标为 `/dashboard/notes`。

### 页头与工具栏

- 删除标题右侧“持续保存”，只保留唯一的自动保存状态。
- 评论与协作按钮并排放在页头右侧，并从工具栏删除。
- 面包屑控制在约 32px 的紧凑高度，不形成额外大块顶部空间。
- “+”打开锚定按钮下方的插入 Popover，包含待办、引用、代码块、分割线、表格、图片和链接。
- 插入 Popover 支持点击外部、Esc 和再次点击按钮关闭，不再使用右侧 Toast。

### 文本选择浮层与评论

- 选择文本后的浮层改为轻量浅色 Popover，只保留 AI、复制和评论等上下文操作。
- 移除与主工具栏重复的加粗、斜体、下划线。
- 点击评论仅打开输入界面；评论服务端提交成功后才创建文本标记。
- 取消、关闭或提交失败时不写入持久标记；历史遗留的无真实评论标记在回放时忽略。

### 大纲

- 视口宽度不小于 1280px 时，大纲使用正文右侧既有空白区，不缩窄正文内容列。
- 大纲条目点击后平滑滚动至对应标题，并预留固定工具栏的顶部偏移。
- 用户可隐藏大纲；隐藏后保留细线提示区域，鼠标或键盘进入时临时展开，点击可固定恢复。
- 768–1279px 使用独立大纲抽屉；小于 768px 同样使用抽屉并覆盖正文，不改变正文宽度。

### 笔记属性与历史版本

- 删除常驻右侧属性栏及其收起轨道。
- 页头“笔记属性”按钮打开轻量 Popover；点击外部或 Esc 关闭。
- 分类、附属分类、标签保留原行为。
- “查看历史版本”放在 Popover 底部，作为低频次级入口。

### 全屏

- 全屏容器使用固定视口高度并提供独立纵向滚动。
- 工具栏保持可见，正文区域可持续滚动。
- 进入与退出全屏时保留正文滚动位置。

## 响应式与无障碍

- 所有 hover 才显示的入口同时支持 `focus-within`，不能依赖鼠标才能操作。
- Popover/抽屉支持 Esc 关闭、合理焦点回退及明确的 `aria-label`。
- 窄屏同一时刻只展示一个覆盖式面板。
- 点击大纲、评论或属性入口不得导致正文宽度突变。

## UI 库边界

- 通用按钮继续使用共享 `Button`。
- 新增一个共享轻量 Popover 基础样式/组件；插入菜单和笔记属性复用它，不各自复制弹层实现。
- 编辑器专属布局、边缘触点和大纲样式保留在 `editor-tokens.css`。
- 不新增与现有 Dialog、Drawer、Toast 职责重叠的组件。

## 验收

- 页头、工具栏和侧栏不存在重复评论、协作或左右面板入口。
- 返回入口位于左栏上部并返回“我的笔记”。
- 插入菜单及属性 Popover 可通过外部点击和 Esc 关闭。
- 未成功提交评论时不产生或保留文本标记。
- 大纲点击定位准确，隐藏与悬停恢复正常。
- 全屏模式可滚动且退出后位置不跳变。
- 运行编辑器相关测试、类型检查，最后只执行一次完整测试、Lint 和构建。
