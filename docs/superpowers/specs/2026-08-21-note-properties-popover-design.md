# 笔记属性弹窗视觉还原设计

## 目标

将编辑器中的“笔记属性”弹窗严格还原为 `docs/ui-mockups/editor-properties-comments-design.html` 中的设计效果。桌面端以设计稿为唯一视觉基准；移动端保留现有响应式行为，并同步相同的视觉语言。

## 范围

- 调整 `NoteEditorMetadataPanel` 与 `EditorNoteProperties` 相关结构和样式。
- 保留分类选择、标签创建与切换、清空、只读态、加载态、错误态和历史版本入口的现有业务行为。
- 保留自定义分类下拉的键盘操作能力，并使关闭态与展开态遵循弹窗的视觉规范。
- 不修改评论侧栏，不开展无关重构。

## 视觉规格

### 弹窗容器

- 桌面端保持右上角浮层定位，宽度沿用设计稿对应的紧凑比例，并受视口宽度约束。
- 使用 1px 中性边框、10px 圆角、白色面板背景和设计稿中的柔和下投影。
- 内容超出视口时允许纵向滚动，但不破坏标题、正文和底部区域的分隔关系。

### 标题栏

- 高度 48px，左右内边距 16px。
- 标题为 14px、700 字重。
- 关闭按钮为 28px 方形点击区域、7px 圆角；图标为 18px。
- 标题栏底部使用 1px 分隔线。

### 正文与表单

- 正文上、左右、下内边距分别为 14px、16px、16px。
- 分类区与标签区之间使用 1px 分隔线；标签区顶部留 16px。
- 字段标题为 12px，辅助提示为 11px，标题下方间距 8px。
- 分类选择框和标签输入框高度 40px、圆角 8px、字号 13px。
- 输入框与“清空”按钮间距为 8px；“清空”为无边框文本按钮。
- 创建标签入口位于输入行下方 8px，左对齐并使用 accent 色。
- 标签列表顶部间距 8px，chip 高度 30px、胶囊圆角、水平间距 6px；选中态使用 accent 背景和白色文字。

### 底部入口

- 使用独立的顶部边框与 12px × 16px 内边距。
- 历史版本入口为 12px、600 字重的 accent 文本，图标为 14px，图文间距 6px。

## 交互与状态

- 分类下拉支持鼠标、键盘方向键、Enter、Escape 和失焦关闭。
- 输入标签后按 Enter 创建；有输入内容时显示创建入口。
- 只读态禁止分类、标签和清空操作，不改变现有权限判断。
- 加载态和错误态保留现有提示与禁用逻辑。
- 所有图标按钮保留可访问名称和可见焦点状态。

## 响应式策略

- 桌面端严格采用上述尺寸。
- 小屏幕继续使用现有定位和宽度约束，弹窗不得超出视口。
- 小屏幕仅允许为防止溢出进行宽度收缩，不改变组件层级、间距关系和视觉状态。

## 验证

- 先补充或调整组件测试，覆盖弹窗结构、分类选择、标签创建、清空与关闭行为。
- 运行相关前端测试、类型检查或构建。
- 启动本地页面，在桌面视口截图，与设计稿逐项对照容器尺寸、圆角、间距、字体、边框、阴影和控件状态。
- 检查移动视口，确认弹窗无横向溢出且功能可用。
