# Dashboard 全站简洁界面统一设计

## 目标

在现有 Calm Minimal 视觉基础上，参考语雀的信息架构，统一“我的笔记”管理页与编辑器工作区，解决返回入口重复、正文卡片嵌套感明显、文档列表层级过重，以及窄屏下侧栏和控制按钮相互遮挡的问题。

本轮统一 Dashboard 页面外观与响应式行为，不新增分类、标签或其他业务流程。

本轮最终范围为所有登录后的 Dashboard 页面：仪表盘、我的笔记、编辑器、知识库、活动日志、分类、标签、设置、通知，以及白板和思维导图的工作台入口。登录、注册、邀请接受和嵌入展示页面不在本轮范围内。

## 全局工作台框架

### 侧栏

侧栏采用平面分组导航，不再把每个入口绘制成独立卡片：

- 主导航：仪表盘、我的笔记、知识库、活动日志。
- 管理分组：分类管理、标签管理。
- 设置固定在侧栏底部。
- 退出登录移入用户菜单，避免独立账户区与页头用户入口重复。
- 选中态只使用浅色背景、主色图标和文字；删除装饰竖线、双层图标框和重复副标题。

1024px 以下侧栏变为抽屉，关闭后不占用内容宽度。

### 顶部栏

顶部栏只保留侧栏开关、面包屑、主题、通知和用户菜单。API 延迟、重试和同步等技术状态收进轻量状态入口，不在主操作区持续展开。设置只从侧栏或用户菜单进入，避免重复入口。

### 页面骨架

所有 Dashboard 页面统一使用：

- 紧凑标题区：页面名称、简短说明和一个主操作。
- 平面内容分区：细分隔线或轻边框，不堆叠厚阴影卡片。
- 统一筛选栏、列表、空状态和分页。
- 稳定的产品主色按钮，不使用渐变主按钮。

共享工作台结构放入 `components/dashboard`，基础按钮、输入框等继续由 `components/ui` 提供。页面专属内容留在对应业务目录，不为单次样式建立全局组件。

## 页面迁移

- 仪表盘：简洁概览、最近笔记和必要统计，删除重复卡片层级。
- 知识库、分类、标签：统一管理列表、工具栏和空状态。
- 活动日志、通知：统一时间线或消息列表，不使用悬浮卡片墙。
- 设置：采用设置目录与表单内容的清晰两栏结构，窄屏改为单栏。
- 白板、思维导图：工作台入口遵循全局框架；具体画布继续使用沉浸式布局。
- 页面功能、API、权限和路由保持不变，只调整信息层级与呈现。

## 我的笔记管理页

“我的笔记”作为编辑器的上游入口，采用紧凑文档管理布局：

- 顶部只保留主题、通知、用户及必要的同步状态，弱化技术状态和重复操作。
- “新建笔记”使用稳定的产品主色按钮，不使用高饱和渐变。
- 搜索、筛选、每页数量及分页整合为紧凑控制区，避免分页脱离内容列表。
- 笔记内容改为更适合扫描的紧凑列表或自适应网格，减少大圆角、厚阴影和无意义留白。
- “猜你喜欢”和“继续写作”降级为辅助区域；窄屏时移动到主列表下方，不挤压主内容。
- 左侧导航使用平面列表和统一选中态，与编辑器笔记目录共享颜色、间距和图标规则。

页面保留现有搜索、筛选、批量操作、分页、编辑和删除能力，不改变 API 与权限行为。

## 信息架构

### 左侧笔记目录

左侧栏由四部分组成：

1. 品牌与工作区标识。
2. 笔记搜索框。
3. 当前用户可访问的笔记目录列表。
4. 底部唯一的“返回工作台”入口。

目录列表高亮当前笔记，点击其他条目直接进入对应编辑页。删除现有“当前笔记”和“全部笔记”两个伪导航按钮，同时删除页头“返回笔记”，避免多个控件执行相同的离开编辑器逻辑。

搜索只过滤已经加载的目录数据，不在本轮引入新的全局搜索协议。加载失败时保留当前笔记条目，并显示简洁的目录不可用状态，不影响正文编辑。

## 编辑画布

正文采用开放式文档画布：工具栏下方直接进入居中的文章内容区，不再呈现带边框、阴影和重复背景的卡片。

DOM 结构只保留以下职责边界：

- 编辑器外层：提供正文宽度、垂直空间和全屏定位。
- Tiptap 容器：承载编辑实例和点击聚焦。
- 可编辑节点：由 Tiptap/ProseMirror 管理。
- 评论提示和 `aria-live` 状态：分别服务评论定位及辅助技术。

必要的结构层不等于视觉层。中间容器保持透明且不绘制边框、阴影或不同底色，使页面看起来是连续的编辑区域。

## 响应式行为

### 宽屏

桌面端保持左侧目录、正文和右侧属性三栏布局。折叠后的侧栏只保留一个清晰的恢复按钮，不与页头控制重复。

### 窄屏

在 1024px 以下，左右栏改为覆盖式抽屉，不参与正文网格宽度计算：

- 打开左侧目录时自动关闭右侧属性。
- 打开右侧属性时自动关闭左侧目录。
- 抽屉内部提供关闭入口。
- 关闭抽屉后正文占据完整可用宽度。

工具栏保持单行。中等宽度优先收起说明文字和低频动作；手机宽度允许工具栏内部横向滚动，但页面本身不得横向滚动。

## 组件与 UI 库边界

- 通用按钮、输入框等基础原语继续位于 `notes-frontend/src/components/ui`。
- 笔记目录、编辑器侧栏、属性面板和工具栏菜单位于 `notes-frontend/src/components/editor`。
- 编辑器尺寸、断点、画布宽度及表面样式统一维护在 `notes-frontend/src/styles/editor-tokens.css`。
- 单次使用的编辑器布局不提升为全局 UI 组件，不新增第三方 UI 库。

## 数据与交互

左侧目录复用现有 notes API 和现有路由：

- 初次进入编辑器时加载轻量笔记列表。
- 当前笔记始终出现在目录中并保持高亮。
- 点击条目通过 Next.js 路由进入 `/dashboard/notes/:id`。
- 搜索在客户端按标题过滤当前列表。
- “返回工作台”进入 `/dashboard`，是编辑器内唯一的工作台返回入口。

## 测试与验收

自动化契约覆盖：

- 全局侧栏采用平面导航，不渲染装饰竖线和重复副标题。
- 顶部栏不持续展开 API 延迟、重试和同步操作。
- Dashboard 页面共享标题、操作、列表和响应式规则，且不使用渐变主按钮。
- “我的笔记”页不再使用渐变主按钮和大面积浮动卡片。
- 搜索、筛选与分页在不同宽度下保持紧凑且不重叠。
- 笔记主列表与辅助推荐区域具有明确的主次关系。
- 编辑页只存在一个“返回工作台”出口，不再渲染“当前笔记 / 全部笔记 / 返回笔记”。
- 目录能够展示、高亮、筛选和切换笔记。
- 正文容器不再使用卡片边框和阴影。
- 1024px 以下左右抽屉互斥，关闭后释放正文轨道。
- 侧栏恢复按钮具有唯一、明确的可访问名称。

浏览器验收抽查仪表盘、我的笔记、知识库、分类、设置和编辑器，并在 1440、1024、768 和 375px 检查页面横向溢出、导航和抽屉遮挡、工具栏滚动、正文宽度、控制按钮重叠及控制台错误。自动化测试覆盖其余页面的共享布局契约。
