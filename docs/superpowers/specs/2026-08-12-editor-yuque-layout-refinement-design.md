# 编辑器语雀式布局精修设计

## 目标

在现有 Calm Minimal 视觉基础上，参考语雀编辑器的信息架构，解决编辑页返回入口重复、正文卡片嵌套感明显，以及窄屏下侧栏和控制按钮相互遮挡的问题。

本轮只调整编辑器工作区，不扩展分类、标签或其他业务流程。

## 信息架构

### 左侧笔记目录

左侧栏由四部分组成：

1. 品牌与工作区标识。
2. 笔记搜索框。
3. 当前用户可访问的笔记目录列表。
4. 底部唯一的“返回工作台”入口。

目录列表高亮当前笔记，点击其他条目直接进入对应编辑页。删除现有“当前笔记”和“全部笔记”两个伪导航按钮，同时删除页头“返回笔记”，避免多个控件执行相同的离开编辑器逻辑。

搜索只过滤已经加载的目录数据，不在本轮引入新的全局搜索协议。加载失败时保留当前笔记条目，并显示简洁的目录不可用状态，不影响正文编辑。

## 编辑画布

正文采用开放式文档画布：工具栏下方直接进入居中的文章内容区，不再呈现带边框、阴影和重复背景的卡片。

DOM 结构只保留以下职责边界：

- 编辑器外层：提供正文宽度、垂直空间和全屏定位。
- Tiptap 容器：承载编辑实例和点击聚焦。
- 可编辑节点：由 Tiptap/ProseMirror 管理。
- 评论提示和 `aria-live` 状态：分别服务评论定位及辅助技术。

必要的结构层不等于视觉层。中间容器保持透明且不绘制边框、阴影或不同底色，使页面看起来是连续的编辑区域。

## 响应式行为

### 宽屏

桌面端保持左侧目录、正文和右侧属性三栏布局。折叠后的侧栏只保留一个清晰的恢复按钮，不与页头控制重复。

### 窄屏

在 1024px 以下，左右栏改为覆盖式抽屉，不参与正文网格宽度计算：

- 打开左侧目录时自动关闭右侧属性。
- 打开右侧属性时自动关闭左侧目录。
- 抽屉内部提供关闭入口。
- 关闭抽屉后正文占据完整可用宽度。

工具栏保持单行。中等宽度优先收起说明文字和低频动作；手机宽度允许工具栏内部横向滚动，但页面本身不得横向滚动。

## 组件与 UI 库边界

- 通用按钮、输入框等基础原语继续位于 `notes-frontend/src/components/ui`。
- 笔记目录、编辑器侧栏、属性面板和工具栏菜单位于 `notes-frontend/src/components/editor`。
- 编辑器尺寸、断点、画布宽度及表面样式统一维护在 `notes-frontend/src/styles/editor-tokens.css`。
- 单次使用的编辑器布局不提升为全局 UI 组件，不新增第三方 UI 库。

## 数据与交互

左侧目录复用现有 notes API 和现有路由：

- 初次进入编辑器时加载轻量笔记列表。
- 当前笔记始终出现在目录中并保持高亮。
- 点击条目通过 Next.js 路由进入 `/dashboard/notes/:id`。
- 搜索在客户端按标题过滤当前列表。
- “返回工作台”进入 `/dashboard`，是编辑器内唯一的工作台返回入口。

## 测试与验收

自动化契约覆盖：

- 编辑页只存在一个“返回工作台”出口，不再渲染“当前笔记 / 全部笔记 / 返回笔记”。
- 目录能够展示、高亮、筛选和切换笔记。
- 正文容器不再使用卡片边框和阴影。
- 1024px 以下左右抽屉互斥，关闭后释放正文轨道。
- 侧栏恢复按钮具有唯一、明确的可访问名称。

浏览器验收覆盖 1440、1024、768 和 375px，检查页面横向溢出、抽屉遮挡、工具栏滚动、正文宽度、控制按钮重叠及控制台错误。
