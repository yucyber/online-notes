# 标签输入与 ID 契约整理方案

## 目标

统一前端实体标识为 `id`，删除笔记属性相关链路中的 `_id` 兼容；复用新建页与编辑页的标签匹配、创建逻辑；让中文逗号 `，`、英文逗号 `,` 和空白都能分隔多个标签。

## 设计

- 前端业务代码只读取 `id`。MongoDB 的 `_id` 由后端序列化层转换，不在组件、hook 或页面中兜底。
- 将标签输入解析为独立纯函数，统一完成分隔、trim、过滤空值和去重。
- 将“按名称匹配已有标签，否则创建标签”的循环提取为公共异步函数，返回标签 ID 与新建标签；调用方负责更新各自状态。
- 新建页继续允许单个标签创建失败后处理其他标签；编辑页维持失败时抛错。公共函数通过调用方提供的创建函数承接该差异，不加入策略开关。
- `EditorNoteProperties` 使用公共解析函数，不再自行维护分隔正则。

## 验证

- 中文逗号、英文逗号、混合空白可以解析为多个去重标签。
- 已有标签不重复创建，缺失标签仅创建一次。
- 新建页和编辑页相关测试、TypeScript 与 ESLint 通过。
