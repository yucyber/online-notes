# 项目工作进度总结（截至 2026-08-06）

## 1. 项目概览

本项目是一个全栈在线知识笔记平台，当前仓库采用多子项目结构：

- `notes-frontend/`：Next.js + TypeScript 前端，覆盖登录注册、仪表盘、笔记、分类、标签、知识库、通知、活动、设置、看板与思维导图等页面。
- `notes-backend/`：NestJS + TypeScript 后端，使用 MongoDB/Mongoose，提供认证、笔记、分类、标签、仪表盘、协作、版本、评论、通知、审计、语义检索、AI、知识库、看板、思维导图等模块。
- `y-websocket/`：独立协作 WebSocket 服务，面向 Tiptap/Yjs 实时协作场景，已补充 JWT 密钥加载与 URL token 脱敏测试。
- `docs/` 与 `docs/superpowers/`：沉淀架构、发布说明、API 契约漂移、AI 路线、稳定性改造计划和交接材料。

当前 Git 分支为 `codex/note-cache-service`，HEAD 为 `7832f6d feat: add knowledge graph frontend entry`。远端仓库配置为 `git@github.com:yucyber/online-notes.git`。

## 3. 最近分支成果

当前分支相对 `master` 主要新增和修复如下：

- 抽离 `NoteCacheService`，为笔记列表增加 Redis 读缓存，缓存失败不影响主查询。
- 接入统一 AI Gateway，默认文本模型走 SenseNova，推理模型走 MiMo，embedding/rerank 走 SiliconFlow。
- 增加 AI Run 审计底座，记录 AI 工作流开始、成功和失败状态。
- 增强 AI 输出校验与修复，覆盖 Mermaid、Mindmap JSON、聚合摘要和知识图谱提案。
- 增加聚合摘要工作流，支持将多篇笔记分块后再合成最终摘要。
- 增加知识库边界模型与接口，支持用户维度知识库、笔记加入/移除和可读权限检查。
- 增加知识图谱构建提案，并限制在单个知识库边界内生成。
- 增加知识图谱节点和边的持久化，支持读取与替换知识库图谱。
- 增加知识库前端入口，支持创建知识库、浏览关联笔记、从笔记列表加入知识库、生成并保存图谱。
- 修复前后端联调中的模块循环依赖和登录测试账号信息不一致问题。
- 加固 Tiptap IndexedDB/Yjs 持久化错误处理，避免开发覆盖层被内部异常污染。
- 加固 `y-websocket` JWT 密钥加载，允许从后端 `.env` 读取本地 JWT_SECRET，并对 URL token 做日志脱敏。
